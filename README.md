## 📌 Featured Projects

| Project | What it does | Built with |
|---|---|---|
| **[AgriSmart AI](https://github.com/GokulChowdary7926/AgriSmart-AI)** | Bilingual (English/Tamil) agriculture platform: crop recommendations, image-based disease detection, weather/market insights, and government-scheme guidance, with a fallback-first AI chat chain (Perplexity → local LLM → rule engine). | React, Vite, Node.js, Express, MongoDB |
| **[AIVOA.AI](https://github.com/GokulChowdary7926/AIVOA.AI)** | End-to-end AI complaint-management system for pharma, compliant with GMP/21 CFR Part 211/ICH Q10. Runs complaint intake through a 7-node LangGraph agent pipeline (extraction, completeness scoring, duplicate detection, risk classification) powered by Groq's `gemma2-9b-it`. | FastAPI, React, Redux Toolkit, LangGraph, SQLAlchemy |
| **[Lesson-Generator](https://github.com/GokulChowdary7926/Lesson-Generator)** | Autonomous agentic system that drafts beginner-friendly lessons on any technical topic, grades them against a 6-point rubric, and regenerates failed drafts — with a self-evolving memory that turns past failures into rules for future runs. | Python, LangGraph, Anthropic/OpenAI SDKs |
| **[Crop-Disease-Detection](https://github.com/GokulChowdary7926/Crop-Disease-Detection)** | Computer-vision web app that detects plant diseases from images using a YOLOv8 model, and returns disease info, prevention steps, and treatment guidance. | Python, YOLOv8, Streamlit |
| **[smart-courier-routing](https://github.com/GokulChowdary7926/smart-courier-routing)** | Delivery-route optimizer: plots a warehouse and delivery points on an interactive map, then computes efficient routes with Dijkstra's/A* and clusters stops using Union-Find for multi-agent routing. | JavaScript, Google Maps API |
| **[Emergency-Ambulance-Simulator](https://github.com/GokulChowdary7926/Emergency-Ambulance-Simulator)** | Browser-based 3D ambulance-driving simulation — dispatch alerts, traffic-signal "green corridor" logic, and patient vital-sign monitoring — rendered in real time. | React, Three.js |
